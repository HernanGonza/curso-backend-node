01¿Qué es un Array?

📋
Array = una lista ordenada de valores.
Un array guarda múltiples valores en una estructura, en un orden específico. Cada valor tiene un índice que empieza desde 0.
JavaScript
const frutas = ['manzana', 'banana', 'uva'];
const nums = [10, 20, 30, 40, 50];
const mixto = ['Ana', 25, true, null];
const vacio = [];

const colores = ['rojo', 'verde', 'azul'];
console.log(colores[0]);              // 'rojo'
console.log(colores[1]);              // 'verde'
console.log(colores[2]);              // 'azul'
console.log(colores[3]);              // undefined
console.log(colores.length);          // 3
console.log(colores[colores.length - 1]); // 'azul' - último

02Sintaxis de Métodos

💡
Los métodos son acciones que podemos hacer sobre un array.
La sintaxis es: nombreDelArray.nombreMetodo(parámetros)
El punto . significa "accede al método del array".
JavaScript
const arr = ['a', 'b', 'c'];

// nombreDelArray . nombreMetodo ( parámetros )
//      ↑         ↑       ↑          ↑
//    el array    punto  método   lo que pasas

// Ejemplos:
arr.push('d');              // agregar 'd' al final
arr.pop();                  // eliminar el último
arr.includes('a');          // ¿contiene 'a'?
arr.indexOf('b');           // ¿en qué posición está 'b'?

// Algunos métodos necesitan información
arr.slice(1, 3);            // copia desde pos 1 hasta 3
arr.splice(0, 1);           // elimina 1 elemento desde pos 0

console.log(arr);           // ver resultado

03Agregar y Eliminar Elementos

➕
Los arrays en JavaScript son dinámicos: podés agregar y eliminar elementos en cualquier momento.

push() — Agrega al FINAL:

JavaScript
const arr = ['a', 'b'];
arr.push('c');
console.log(arr);  // ['a', 'b', 'c']

pop() — Elimina el ÚLTIMO:

JavaScript
const arr = ['a', 'b', 'c'];
const ultimo = arr.pop();
console.log(ultimo);  // 'c'
console.log(arr);     // ['a', 'b']

unshift() — Agrega al INICIO:

JavaScript
const arr = ['b', 'c'];
arr.unshift('a');
console.log(arr);  // ['a', 'b', 'c']

shift() — Elimina el PRIMERO:

JavaScript
const arr = ['a', 'b', 'c'];
const primero = arr.shift();
console.log(primero);  // 'a'
console.log(arr);      // ['b', 'c']

splice() — En cualquier posición:

JavaScript
const dias = ['lun', 'mar', 'jue', 'vie'];
dias.splice(2, 0, 'mie');  // inserta 'mie' en pos 2
console.log(dias);  // ['lun', 'mar', 'mie', 'jue', 'vie']
dias.splice(0, 1);  // elimina primer elemento
console.log(dias);  // ['mar', 'mie', 'jue', 'vie']

slice() — Copia parte sin modificar:

JavaScript
const nums = [10, 20, 30, 40, 50];
console.log(nums.slice(1, 3));    // [20, 30]
console.log(nums.slice(3));       // [40, 50]
console.log(nums.slice(-2));      // [40, 50]
console.log(nums);                // [10, 20, 30, 40, 50] - SIN cambio

04Buscar Elementos en un Array

🔍
Diferentes formas de buscar según lo que necesites.
JavaScript
// includes() - ¿existe el valor?
const roles = ['admin', 'editor'];
console.log(roles.includes('admin'));      // true
console.log(roles.includes('superuser'));  // false

// indexOf() - ¿en qué posición?
console.log(roles.indexOf('editor'));      // 1
console.log(roles.indexOf('superuser'));   // -1

// find() - el elemento que cumple la condición
const usuarios = [
  {id: 1, nombre: 'Ana', activo: true},
  {id: 2, nombre: 'Bruno', activo: false},
];
const usuario = usuarios.find(u => u.id === 2);
console.log(usuario);  // {id: 2, nombre: 'Bruno'...}

// some() - ¿AL MENOS UNO cumple?
console.log(usuarios.some(u => u.activo));  // true

// every() - ¿TODOS cumplen?
console.log(usuarios.every(u => u.activo)); // false

05Otros Métodos Útiles

⚙️
join, reverse, sort, concat, flat, spread operator.
JavaScript
// join() - convierte a string
const permisos = ['leer', 'escribir', 'borrar'];
console.log(permisos.join(', '));  // 'leer, escribir, borrar'

// sort() con números - CUIDADO
const precios = [100, 20, 300, 5];
precios.sort((a, b) => a - b);
console.log(precios);  // [5, 20, 100, 300]

// concat - une dos arrays
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
console.log(arr1.concat(arr2));  // [1, 2, 3, 4, 5, 6]

// spread operator - forma moderna
const copia = [...arr1];
const unidos = [...arr1, ...arr2];
console.log(unidos);  // [1, 2, 3, 4, 5, 6]
