PostgreSQL Básico

Escribí tu primer SQL real: creá una tabla con CREATE TABLE, insertá filas con INSERT INTO, y consultá los datos con SELECT y WHERE en pgAdmin o VS Code.

60 minutos Requiere Clase 25
Objetivos de la clase
  • Conectarse a una base de datos PostgreSQL y ejecutar sentencias SQL desde pgAdmin o VS Code.
  • Crear una tabla nueva utilizando CREATE TABLE, definiendo columnas y sus tipos de dato.
  • Aplicar restricciones básicas: PRIMARY KEY, NOT NULL y la columna autoincremental SERIAL.
  • Insertar filas nuevas en una tabla utilizando INSERT INTO.
  • Consultar los datos de una tabla utilizando SELECT, incluyendo selección de columnas específicas.
  • Filtrar resultados de una consulta utilizando la cláusula WHERE con operadores de comparación.

01Conectando a la Base de Datos

Antes de escribir la primera sentencia SQL, hace falta tener una base de datos creada dentro del servidor de PostgreSQL. Una base de datos es, conceptualmente, un contenedor separado de tablas: un mismo servidor de PostgreSQL puede alojar varias bases de datos distintas, cada una completamente aislada de las demás.

sql
-- Esto se ejecuta una sola vez, para crear el contenedor de la tienda virtual
CREATE DATABASE tienda_virtual;

Una vez creada la base de datos, te conectás a ella (desde pgAdmin haciendo clic sobre su nombre, o desde VS Code con SQLTools seleccionándola como conexión activa) y ahí es donde vas a escribir el resto de las sentencias SQL de esta clase: creación de tablas, inserciones y consultas.

💡
Analogía práctica: Si el servidor de PostgreSQL es el edificio completo, cada base de datos es un departamento distinto dentro de ese edificio. Las tablas de la tienda virtual viven dentro del departamento tienda_virtual, separadas de cualquier otro proyecto que pudieras tener en el mismo servidor.

02CREATE TABLE: Definiendo la Estructura de una Tabla

La sentencia CREATE TABLE es la que efectivamente crea una tabla nueva dentro de la base de datos, especificando el nombre de cada columna junto con su tipo de dato, tal como repasamos conceptualmente en la Clase 25.

sql
CREATE TABLE productos (
  id SERIAL PRIMARY KEY,
  nombre VARCHAR(100) NOT NULL,
  precio NUMERIC(10,2) NOT NULL,
  stock INTEGER DEFAULT 0
);

Cada línea dentro de los paréntesis define una columna: primero su nombre, después su tipo de dato, y opcionalmente restricciones adicionales. La sentencia completa termina siempre con punto y coma.

⚠️
Errores comunes al empezar: Olvidar el punto y coma al final, escribir el nombre de una tabla que ya existe (PostgreSQL va a rechazar la creación con un error), o usar un tipo de dato mal escrito. PostgreSQL es estricto: si hay un error de sintaxis, ninguna parte de la sentencia se ejecuta.

03Restricciones Básicas: PRIMARY KEY, NOT NULL y SERIAL

Las restricciones (constraints) son reglas que PostgreSQL aplica automáticamente sobre una columna, rechazando cualquier operación que las viole. Ya usamos tres de las más comunes en el ejemplo anterior.

RestricciónQué garantiza
PRIMARY KEYLa columna es la clave primaria de la tabla: valores únicos y nunca vacíos.
NOT NULLLa columna no puede quedar vacía (sin valor) en ninguna fila.
SERIALTipo especial que autogenera un número entero incremental (1, 2, 3...) en cada INSERT, sin necesidad de indicarlo manualmente.
DEFAULTSi no se especifica un valor al insertar, la columna toma automáticamente el valor indicado.
🛡️
Por qué SERIAL es tan común: Prácticamente todas las tablas usan id SERIAL PRIMARY KEY como primera columna: PostgreSQL se encarga solo de generar identificadores únicos y crecientes, sin que el programador tenga que calcularlos manualmente.

04INSERT INTO: Agregando Filas a la Tabla

Una vez creada la tabla, INSERT INTO es la sentencia que agrega una fila nueva. Se indica el nombre de la tabla, la lista de columnas a completar, y los valores correspondientes en el mismo orden.

sql
INSERT INTO productos (nombre, precio, stock)
VALUES ('Mouse inalambrico', 4500, 20);

-- Se pueden insertar varias filas en una sola sentencia:
INSERT INTO productos (nombre, precio, stock)
VALUES
  ('Teclado mecanico', 12000, 15),
  ('Monitor 24 pulgadas', 45000, 8);
⚠️
Sobre la columna id: Como id es SERIAL, nunca se incluye en el INSERT: PostgreSQL la genera solo. Si se intenta insertar un valor manual en una columna SERIAL, la tabla lo permite, pero rompe la generación automática de los próximos ids, así que se evita salvo casos muy puntuales.

05SELECT: Consultando los Datos

SELECT es, sin dudas, la sentencia SQL más usada: permite consultar y devolver filas de una tabla. El asterisco * es un atajo que significa "todas las columnas"; también se puede pedir un subconjunto específico, separadas por coma.

sql
-- Todas las columnas, todas las filas
SELECT * FROM productos;

-- Solo columnas especificas
SELECT nombre, precio FROM productos;

El orden de las columnas en el resultado sigue exactamente el orden en que se las pidió en el SELECT, no necesariamente el orden en que fueron creadas en la tabla.

06WHERE: Filtrando Resultados con Condiciones

Sin una condición, SELECT devuelve absolutamente todas las filas de la tabla. La cláusula WHERE permite filtrar, devolviendo únicamente las filas que cumplen una condición determinada.

sql
-- Productos con precio mayor a 10000
SELECT * FROM productos WHERE precio > 10000;

-- Producto con un nombre exacto
SELECT * FROM productos WHERE nombre = 'Mouse inalambrico';

-- Combinando condiciones con AND
SELECT * FROM productos WHERE precio > 5000 AND stock > 0;
OperadorSignificado
=Igual a.
> / <Mayor que / menor que.
>= / <=Mayor o igual / menor o igual.
!= o <>Distinto de.
AND / ORCombina dos o más condiciones a la vez.
💡
Analogía práctica: SELECT * FROM productos es como pedir \u00abmostrame el fichero completo\u00bb. Agregar WHERE precio > 10000 es como pedirle a alguien que revise el fichero y solo te traiga las fichas que cumplen esa condición, sin que vos tengas que revisar todo a mano.
