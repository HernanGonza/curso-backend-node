00Programación Orientada a Objetos (POO)

Antes de adentrarnos en la sintaxis de JavaScript, es clave comprender el plano conceptual. La Programación Orientada a Objetos es un paradigma de programación (un estilo o modelo de diseño de software) que organiza el código alrededor de "objetos" en lugar de funciones o lógica secuencial pura.

🏛️
Abstracción del mundo real: En la POO, buscamos modelar elementos del mundo real o de nuestro dominio de negocio en estructuras de código que combinan características y comportamientos bajo una sola entidad autónoma.

Imagina un sistema de e-commerce: en lugar de tener variables sueltas para el nombre de un usuario, su contraseña y su estado de conexión por todo el script, conceptualizamos un objeto unificado Usuario que posee datos específicos y puede realizar acciones definidas.

01¿Qué es un Objeto en JavaScript?

📋
Objeto = un conjunto de propiedades clave: valor.
Un objeto agrupa datos relacionados en una sola estructura. Cada dato tiene un nombre único llamado clave (o propiedad) y un valor asociado.

A diferencia de los Arrays que utilizan índices numéricos ordenados de 0 en adelante, los objetos utilizan nombres descriptivos (strings) para indexar sus valores. En el desarrollo backend, casi todo se representa como un objeto: un usuario de la base de datos, un producto del catálogo, un pedido de compra o una respuesta HTTP.

JavaScript
const usuario = {
  id: 1,                    // clave: valor -> número
  nombre: "Ana García",     // clave: valor -> string
  email: 'ana@mail.com',    // clave: valor -> string
  edad: 28,                 // clave: valor -> número
  esAdmin: false,           // clave: valor -> boolean
  activo: true              // se crea con llaves {}
};

// Acceder a propiedades:
console.log(usuario.nombre);     // "Ana García" (Notación de punto - la más común)
console.log(usuario['email']);   // "ana@mail.com" (Notación de corchetes - útil si la clave es dinámica)

const clave = 'edad';
console.log(usuario[clave]);     // 28 (Acceso dinámico con variable)
console.log(usuario.telefono);   // undefined (La propiedad no existe)

Modificar, agregar y eliminar propiedades:

Los objetos en JavaScript son mutables. Puedes alterar su estructura fácilmente en tiempo de ejecución:

usuario.nombre = 'Ana López'; Modifica una propiedad existente dentro del objeto.
usuario.ciudad = 'Rosario'; Agrega una propiedad totalmente nueva si la clave no existía.
delete usuario.ciudad; Elimina la propiedad por completo del objeto.
'email' in usuario; Devuelve true o false para verificar si la propiedad existe en el objeto.

02Objetos Anidados y Arrays de Objetos

Los objetos pueden contener otras estructuras complejas dentro de sí mismos, incluyendo sub-objetos y arrays. Esta composición jerárquica representa la forma más fiel y común de transferir datos reales en Node.js y APIs modernas.

JavaScript
const pedido = {
  id: 101,
  fecha: '2024-03-15',
  estado: 'pendiente',
  cliente: {                    // Objeto dentro de objeto
    nombre: 'Carlos',
    email: 'carlos@mail.com'
  },
  items: [                      // Array de objetos dentro de objeto
    { producto: 'Teclado', cantidad: 1, precio: 5000 },
    { producto: 'Mouse', cantidad: 2, precio: 2000 }
  ]
};

// Acceder a datos anidados:
console.log(pedido.cliente.nombre);   // 'Carlos'
console.log(pedido.items[0].producto); // 'Teclado'
console.log(pedido.items[1].precio);   // 2000

// Calcular el total del pedido recorriendo el array interno:
let total = 0;
for (const item of pedido.items) {
  total += item.cantidad * item.precio;
}
console.log('Total:', total); // 9000

03Métodos Útiles de Object

⚙️
La clase global Object nos provee de herramientas para extraer datos o clonar estructuras sin mutar los originales de forma directa.
Object.keys(obj) Devuelve un array con todas las claves (propiedades) del objeto.
Object.values(obj) Devuelve un array con todos los valores del objeto.
Object.entries(obj) Devuelve un array de pares bidimensionales [clave, valor].
{ ...obj } Copia un objeto de forma superficial usando el Spread Operator (muy común en backend).
{ ...obj, nueva: valor } Copia el objeto original agregando o sobreescribiendo propiedades en una sola línea.
JavaScript
const producto = { nombre: 'Laptop', precio: 150000, stock: 5 };

console.log(Object.keys(producto));   // ['nombre', 'precio', 'stock']
console.log(Object.values(producto)); // ['Laptop', 150000, 5]
console.log(Object.entries(producto));// [['nombre', 'Laptop'], ['precio', 150000], ['stock', 5]]

// Spread Operator: Copiar y actualizar datos (Inmutabilidad)
const productoActualizado = { ...producto, precio: 140000, stock: 10 };
console.log(productoActualizado);     // { nombre: 'Laptop', precio: 140000, stock: 10 }
console.log(producto.precio);         // 150000 (El objeto original se mantiene intacto!)

// Recorrer las entradas de un objeto de forma elegante:
for (const [clave, valor] of Object.entries(producto)) {
  console.log(`${clave}: ${valor}`);
}

04JSON: El Lenguaje de la Web

JSON significa JavaScript Object Notation. Es un formato de texto plano utilizado de forma universal para representar y transferir datos estructurados. Aunque su sintaxis es idéntica a la declaración de un objeto literal de JavaScript, es un formato completamente independiente del lenguaje.

🌐
Estándar de Comunicación: Prácticamente el 100% de las comunicaciones de red entre un Frontend y un Backend o entre microservicios de APIs externas viajan empaquetados bajo el formato de strings JSON en el cuerpo (body) de las peticiones HTTP.

Principales diferencias entre un Objeto JS y JSON:

Objeto JavaScript JSON (Formato de Texto)
Las claves pueden declararse sin comillas. Las claves SIEMPRE van estrictamente envueltas en comillas dobles.
Soporta comillas simples y dobles indistintamente. Solo acepta comillas dobles tanto para claves como para strings.
Puede contener funciones y métodos ejecutables. Solo admite datos puros: strings, numbers, booleans, null, arrays y objetos.
Vive activo en la memoria RAM como una estructura viva. Es una cadena de caracteres plana lista para enviarse por la red.

Conversión con JSON.stringify y JSON.parse:

JavaScript integra herramientas automáticas nativas para procesar estas transformaciones de forma instantánea:

JavaScript
// 1. JSON.stringify: De Objeto JS -> a String JSON (Para ENVIAR datos)
const usuarioObj = { id: 1, nombre: 'Ana', activo: true };
const jsonString = JSON.stringify(usuarioObj);
console.log(jsonString); // '{"id":1,"nombre":"Ana","activo":true}'
console.log(typeof jsonString); // 'string'

// Uso estético con indentación para archivos o logs (2 espacios):
console.log(JSON.stringify(usuarioObj, null, 2));

// 2. JSON.parse: De String JSON -> a Objeto JS (Para RECIBIR datos)
const jsonRecibido = '{"id":1,"nombre":"Ana","activo":true}';
const objetoParseado = JSON.parse(jsonRecibido);
console.log(objetoParseado.nombre); // 'Ana'
console.log(typeof objetoParseado); // 'object'

// BUENA PRÁCTICA: Proteger JSON.parse con bloques try/catch
// Si el string externo viene corrupto o mal formado, romperá el servidor si no se controla.
try {
  const datosInseguros = JSON.parse('{"id": 5, "incompleto": }'); // Provocará error
} catch (error) {
  console.log('JSON inválido detectado:', error.message);
}

05Destructuring: Extraer Datos Fácilmente

El Destructuring (desestructuración) es una sintaxis moderna introducida en ECMAScript 6 que permite extraer valores directamente desde objetos o arrays y guardarlos en variables individuales usando una sola línea limpia de código. Es extremadamente popular en Node.js.

JavaScript
const persona = { id: 1, nombre: 'Ana', email: 'ana@mail.com', edad: 28 };

// Forma clásica (larga y repetitiva):
// const nombre = persona.nombre;
// const email = persona.email;

// Con Destructuring de Objetos:
const { nombre, email } = persona;
console.log(nombre); // 'Ana'
console.log(email);  // 'ana@mail.com'

// Configuración con valores por defecto (si la propiedad no existía):
const { ciudad = 'Sin ciudad registrado' } = persona;
console.log(ciudad); // 'Sin ciudad registrado'

// Renombrar propiedades al vuelo al extraerlas:
const { nombre: nombreCompleto } = persona;
console.log(nombreCompleto); // 'Ana'

// Destructuring de Arrays (se rige por posiciones en vez de claves):
const numeros = [10, 20, 30, 40, 50];
const [primero, segundo, ...resto] = numeros; // usando rest operator
console.log(primero); // 10
console.log(segundo); // 20
console.log(resto);   // [30, 40, 50] (un array con los restantes)
