00El Paradigma de Programación Orientada a Objetos (POO)

Antes de escribir código, es clave entender el diseño de software. La Programación Orientada a Objetos (POO) es un paradigma de programación; es decir, una forma o un modelo estructurado de pensar y resolver problemas informáticos organizando el código alrededor de "objetos" autogestionados en lugar de variables sueltas o funciones puramente secuenciales.

🏛️
Abstracción de Datos: En el desarrollo de software, la POO nos permite tomar conceptos complejos de la realidad de un negocio (un usuario, una venta, una factura, un ticket de soporte) y modelarlos como entidades lógicas que empaquetan tanto sus características como sus comportamientos.

¿Qué es un Objeto en el concepto de la POO?

Conceptualmente, un **Objeto** es una instancia o entidad concreta que posee:

1. Estado (Atributos / Propiedades): Los datos o características que describen a ese objeto en un momento dado (por ejemplo, el precio de un producto, el nombre del cliente, si la cuenta está activa).

2. Comportamiento (Métodos / Acciones): Las operaciones o funciones que el objeto puede ejecutar (por ejemplo, calcular el IVA, actualizar stock, autenticarse).

En entornos Backend como Node.js, este paradigma es fundamental. Cuando consultamos datos de una base de datos (como Supabase o PostgreSQL), cada registro se nos entrega mapeado exactamente con esta estructura conceptual.

01¿Qué es un Objeto en JavaScript?

En JavaScript, un objeto literal es una de las estructuras de datos fundamentales. Se define como una colección o **conjunto de propiedades compuestas por pares de clave: valor** agrupadas dentro de llaves {}.

📋
Diferencia con los Arrays: Mientras que un Array indexa sus elementos mediante números correlativos ordenados automáticamente (0, 1, 2, etc.), un Objeto asocia cada valor a una clave textual semántica (un nombre descriptivo elegido por vos).
JavaScript
const usuario = {
  id: 1,                    // clave: 'id', valor: 1 (Número)
  nombre: "Ana García",     // clave: 'nombre', valor: "Ana García" (String)
  email: 'ana@mail.com',    // clave: 'email', valor: 'ana@mail.com' (String)
  esAdmin: false,           // clave: 'esAdmin', valor: false (Booleano)
  activo: true              // Los pares se separan por comas
};

Formas de Acceder a las Propiedades

Existen dos sintaxis estandarizadas para leer el valor interno de una clave:

1. Notación de Punto (objeto.propiedad): Es la más limpia, común y la que usarás el 90% del tiempo cuando conozcas el nombre exacto de la propiedad de antemano.

2. Notación de Corchetes (objeto['propiedad']): Es obligatoria si el nombre de la clave se encuentra guardado dentro de otra variable o si contiene caracteres especiales o espacios.

JavaScript
console.log(usuario.nombre);     // "Ana García" (Notación de punto)
console.log(usuario['email']);   // "ana@mail.com" (Notación de corchetes)

// Acceso dinámico por variable:
const propiedadABuscar = 'esAdmin';
console.log(usuario[propiedadABuscar]); // false

console.log(usuario.telefono);   // undefined (Intentar leer una clave inexistente no rompe el programa, devuelve undefined)

02Operaciones Atómicas: Modificar, Agregar y Eliminar

Los objetos en JavaScript son estructuras dinámicas y mutables en memoria, lo que significa que podemos alterar sus datos y su forma en cualquier punto del flujo de ejecución del programa.

1. Modificar una Propiedad Existente

Si la clave ya existe dentro del objeto, simplemente usamos el operador de asignación (=) seguido del nuevo valor para sobreescribir el dato anterior.

JavaScript
const producto = { id: 10, nombre: 'Monitor', precio: 45000 };
producto.precio = 48000; // Modifica el valor asociado a la clave 'precio'
console.log(producto.precio); // 48000

2. Agregar una Nueva Propiedad

Para expandir un objeto, basta con escribir una clave que **no exista previamente** y asignarle un valor. JavaScript la creará inmediatamente en la estructura interna.

JavaScript
producto.stock = 15; // Como 'stock' no existía, se acopla como propiedad nueva
producto['marca'] = 'Logitech'; // También funciona con corchetes
console.log(producto); // { id: 10, nombre: 'Monitor', precio: 48000, stock: 15, marca: 'Logitech' }

3. Eliminar una Propiedad por Completo

Utilizamos la palabra clave nativa delete antes del acceso a la propiedad. Esto remueve físicamente tanto la clave como su valor asignado, haciendo que una consulta posterior a ella retorne undefined.

JavaScript
delete producto.marca; // Remueve la propiedad del mapa de memoria
console.log(producto.marca); // undefined

4. Verificar la Existencia de una Propiedad

Para saber a ciencia cierta si un objeto tiene una clave sin arriesgarnos a evaluar un undefined indirecto, empleamos el operador binario in.

JavaScript
console.log('stock' in producto); // true
console.log('marca' in producto); // false

03Objetos Anidados y Colecciones Complejas

En escenarios reales de Backend, los datos no son planos. Un objeto puede contener sub-objetos u arrays que a su vez contienen más objetos. Esto permite mapear relaciones de datos complejas e intrincadas de manera orgánica.

JavaScript
const pedido = {
  id: 4501,
  fecha: '2026-06-23',
  cliente: {                    // Un objeto como valor de una propiedad
    nombre: 'Carlos Quintana',
    email: 'carlos@mail.com'
  },
  items: [                      // Un Array de objetos como valor
    { articulo: 'Mouse Wireless', cant: 1, precio: 3500 },
    { articulo: 'Pad XL', cant: 2, precio: 1500 }
  ]
};

// Acceso encadenado y preciso:
console.log(pedido.cliente.nombre);   // "Carlos Quintana"
console.log(pedido.items[0].articulo); // "Mouse Wireless"
console.log(pedido.items[1].precio);   // 1500

04Métodos Estáticos de la Clase Object

JavaScript provee una serie de herramientas globales a través del constructor nativo Object que nos permiten transformar objetos en arrays para manipularlos o inspeccionarlos con facilidad.

Object.keys(objeto)

Extrae únicamente las **claves** (los nombres de las propiedades) del objeto y las unifica en un Array de Strings secuencial.

JavaScript
const auto = { marca: 'Toyota', modelo: 'Corolla', anio: 2022 };
const claves = Object.keys(auto);
console.log(claves); // ['marca', 'modelo', 'anio']

Object.values(objeto)

Extrae únicamente los **valores** asociados a cada propiedad y los agrupa ordenadamente en un nuevo Array.

JavaScript
const valores = Object.values(auto);
console.log(valores); // ['Toyota', 'Corolla', 2022]

Object.entries(objeto)

Descompone el objeto por completo transformándolo en un Array bidimensional. Cada elemento interno es un sub-array de dos posiciones que representa la estructura [clave, valor].

JavaScript
const entradas = Object.entries(auto);
console.log(entradas); // [ ['marca', 'Toyota'], ['modelo', 'Corolla'], ['anio', 2022] ]

// Es ideal para recorrer un objeto iterándolo con un bucle for...of:
for (const [clave, valor] of Object.entries(auto)) {
  console.log(`Propiedad: ${clave} -> Valor: ${valor}`);
}

Inmutabilidad con el Spread Operator ({ ...objeto })

En el desarrollo profesional, **mutar objetos directamente está desaconsejado** ya que puede provocar efectos secundarios inesperados en el flujo de datos. Para trabajar de manera inmutable, clonamos las propiedades de un objeto antiguo en uno nuevo usando el *Spread Operator* (operador de propagación `...`).

JavaScript
const autoOriginal = { marca: 'Ford', precio: 20000 };

// Clonamos el objeto original y modificamos o agregamos propiedades en el acto:
const autoActualizado = { ...autoOriginal, precio: 22000, color: 'Rojo' };

console.log(autoActualizado); // { marca: 'Ford', precio: 22000, color: 'Rojo' }
console.log(autoOriginal.precio); // 20000 (¡El objeto original permanece intacto e inalterado en memoria!)

05JSON: Intercambio Universal de Datos

JSON (JavaScript Object Notation) es un **formato estándar basado en texto plano** concebido exclusivamente para representar datos estructurados de forma legible. Aunque deriva directamente de la sintaxis literal de JavaScript, JSON es agnóstico: se procesa en Python, PHP, Java, etc.

⚠️
Diferencia Operativa: Un objeto JavaScript es una estructura de datos viva que reside activa en la memoria RAM del entorno de ejecución. Un JSON es meramente una cadena de caracteres (un String) optimizada para viajar a través del cable en redes de internet (HTTP).

Tabla Comparativa Estricta de Reglas Sintácticas

Regla Léxica Objeto JavaScript Literal Formato JSON (Texto)
Comillas en Claves Opcionales (Ej: nombre: "Ana") SIEMPRE OBLIGATORIAS en comillas dobles (Ej: "nombre": "Ana")
Comillas en Strings Permite comillas simples '', dobles "" o backticks `` ÚNICAMENTE comillas dobles ""
Tipos de datos soportados Números, strings, booleanos, objetos, arrays, funciones y métodos ejecutables. Datos estáticos puros: números, strings, booleanos, null, arrays y sub-objetos. No soporta funciones.
Comas Finales Permite una coma tras el último elemento (Trailing comma). PROHIBIDAS. El último elemento del bloque no debe llevar coma, o fallará el parseo.

Conversión Segura mediante JSON.stringify y JSON.parse

Para interactuar entre la red y nuestro código, el lenguaje expone dos métodos automáticos globales:

1. JSON.stringify(objeto): Serializa un objeto convirtiéndolo en un String de texto listo para ser transmitido hacia el cliente o guardado en un archivo.

2. JSON.parse(textoJSON): Toma un String JSON recibido de la web y lo reconstruye en un objeto operable en la memoria RAM.

JavaScript
const programador = { nombre: 'Enzo', lenguajes: ['JS', 'SQL'] };

// De Objeto a String JSON
const stringEnviado = JSON.stringify(programador);
console.log(stringEnviado); // '{"nombre":"Enzo","lenguajes":["JS","SQL"]}'
console.log(typeof stringEnviado); // "string"

// De String JSON a Objeto (Con Protección Operativa)
const datosRecibidos = '{"nombre":"Enzo","lenguajes":["JS","SQL"]}';

try {
  const objetoJS = JSON.parse(datosRecibidos);
  console.log(objetoJS.nombre); // "Enzo"
} catch (error) {
  // Si el JSON viene mal estructurado (ej: le falta una comilla), JSON.parse arroja una excepción fatal síncrona.
  // En Node.js, si no capturás este error con try/catch, ¡el proceso entero del servidor se detiene de inmediato!
  console.error("No se pudo procesar el JSON, la estructura venía corrupta:", error.message);
}

06Destructuring (Desestructuración)

El Destructuring es una sintaxis abreviada introducida en las versiones modernas de JavaScript (ES6). Nos permite desempaquetar o "extraer" propiedades específicas directamente desde un objeto o array y guardarlas en variables independientes en una única línea de código limpia y auto-descriptiva.

JavaScript
const configServer = { ip: '127.0.0.1', puerto: 8080, dbName: 'produccion' };

// Sintaxis clásica (Larga, tediosa y repetitiva):
// const ip = configServer.ip;
// const puerto = configServer.puerto;

// Usando Destructuring de Objetos:
const { ip, puerto, dbName } = configServer;
console.log(ip);     // '127.0.0.1'
console.log(puerto); // 8080

// Truco avanzado: Definir valores por defecto por si la clave no existe en el objeto
const { protocolo = 'http' } = configServer;
console.log(protocolo); // 'http'
