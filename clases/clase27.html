CRUD con SQL

Completá el CRUD en SQL con UPDATE y DELETE, combiná datos de varias tablas con JOIN, y resumí información con funciones de agregación como COUNT y SUM.

60 minutos Requiere Clase 26
Objetivos de la clase
  • Modificar filas existentes en una tabla utilizando UPDATE junto con WHERE.
  • Eliminar filas de una tabla utilizando DELETE junto con WHERE.
  • Comprender por qué WHERE es obligatorio, en la práctica, en cualquier UPDATE o DELETE.
  • Relacionar dos tablas mediante una clave foránea y combinarlas con JOIN.
  • Utilizar funciones de agregación básicas: COUNT y SUM.
  • Combinar JOIN con funciones de agregación para responder preguntas simples sobre los datos.

01UPDATE: Modificando Filas Existentes

La sentencia UPDATE modifica el valor de una o varias columnas en las filas que cumplen una condición determinada. Se indica la tabla, la nueva asignación con SET, y la condición con WHERE que identifica qué fila (o filas) se van a modificar.

sql
UPDATE productos
SET precio = 5000
WHERE id = 1;

-- Se pueden actualizar varias columnas a la vez, separadas por coma
UPDATE productos
SET precio = 4800, stock = 25
WHERE id = 1;

PostgreSQL siempre responde indicando cuántas filas fueron afectadas por el UPDATE. Ese número es una señal muy útil: si esperabas modificar una sola fila y el resultado dice "3 filas afectadas", algo está mal en tu condición WHERE.

02DELETE: Eliminando Filas

DELETE elimina por completo las filas que cumplen una condición. A diferencia de UPDATE, no se especifican columnas: la fila entera desaparece de la tabla.

sql
DELETE FROM productos
WHERE id = 3;

Al igual que con UPDATE, PostgreSQL devuelve la cantidad de filas eliminadas, lo que sirve como una confirmación rápida de que la operación hizo exactamente lo esperado.

03Por Qué WHERE es Obligatorio en UPDATE y DELETE

Tanto UPDATE como DELETE son sentencias técnicamente válidas sin una cláusula WHERE. El problema es que, sin WHERE, la operación se aplica a absolutamente todas las filas de la tabla, sin excepción.

sql
-- PELIGRO: esto borra TODOS los productos de la tabla, sin excepcion
DELETE FROM productos;

-- PELIGRO: esto pone el precio de TODOS los productos en 0
UPDATE productos SET precio = 0;
⚠️
Regla de oro: Antes de ejecutar cualquier UPDATE o DELETE, primero ejecutá un SELECT con exactamente el mismo WHERE, para confirmar visualmente cuáles son las filas afectadas antes de modificarlas o borrarlas de verdad.

04Preparando una Segunda Tabla Relacionada

Para poder combinar información de dos tablas con JOIN, primero necesitamos una segunda tabla relacionada con productos. Vamos a crear categorias, y a conectar cada producto con una categoría mediante una clave foránea, tal como se explicó de forma conceptual en la Clase 25.

sql
CREATE TABLE categorias (
  id SERIAL PRIMARY KEY,
  nombre VARCHAR(50) NOT NULL
);

ALTER TABLE productos
ADD COLUMN categoria_id INTEGER REFERENCES categorias(id);

INSERT INTO categorias (nombre) VALUES ('Electronica'), ('Accesorios');

UPDATE productos SET categoria_id = 1 WHERE id IN (1, 3);
UPDATE productos SET categoria_id = 2 WHERE id = 2;
🛡️
Sobre REFERENCES: REFERENCES categorias(id) le indica a PostgreSQL que categoria_id solo puede contener valores que efectivamente existan como id en la tabla categorias. Es la forma en que la base de datos protege activamente la integridad de la relación.

05JOIN: Combinando Datos de Varias Tablas

Un JOIN combina filas de dos tablas relacionadas en un único resultado, usando la clave foránea como punto de unión. La variante más usada es INNER JOIN, que devuelve solo las filas que tienen coincidencia en ambas tablas.

sql
SELECT productos.nombre, productos.precio, categorias.nombre AS categoria
FROM productos
INNER JOIN categorias ON productos.categoria_id = categorias.id;

La sintaxis se lee de forma natural: "traeél nombre y precio de productos, unido con categorías, donde el categoria_id de productos coincide con el id de categorías". El alias AS categoria renombra la columna en el resultado, para no confundirla con productos.nombre.

💡
Analogía práctica: Es como cruzar dos planillas de Excel usando una columna en común: una planilla tiene productos con un número de categoría, la otra tiene el nombre de cada categoría según ese número. JOIN hace ese cruce automáticamente, en una sola consulta.

06Funciones de Agregación: COUNT y SUM

Las funciones de agregación calculan un único valor resumen a partir de un conjunto de filas, en lugar de devolver las filas una por una. COUNT cuenta cuántas filas hay, y SUM suma los valores numéricos de una columna.

sql
-- Cuantos productos hay en total?
SELECT COUNT(*) FROM productos;

-- Cual es la suma de todos los precios?
SELECT SUM(precio) FROM productos;

-- Combinando con WHERE: cuantos productos cuestan mas de 5000
SELECT COUNT(*) FROM productos WHERE precio > 5000;

Estas funciones también se pueden combinar con GROUP BY para obtener un resultado por cada grupo (por ejemplo, cuántos productos hay por categoría), aunque esa combinación se profundiza más adelante en el curso.

sql
-- Cuantos productos hay en cada categoria
SELECT categoria_id, COUNT(*)
FROM productos
GROUP BY categoria_id;
