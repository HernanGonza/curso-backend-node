Funciones Flecha

Dominá la sintaxis moderna de JavaScript: funciones flecha con sus variantes, el comportamiento del this, cuándo usarlas y cuándo no, y cómo combinan perfectamente con los métodos de arrays.

60 minutos Requiere Clase 9
Objetivos de la clase
  • Entender la sintaxis de las funciones flecha (arrow functions) y sus variantes.
  • Conocer las distintas formas de escribirlas según la cantidad de parámetros y líneas.
  • Entender la diferencia de comportamiento del this entre funciones tradicionales y flecha.
  • Saber cuándo usar función flecha y cuándo no.
  • Combinar funciones flecha con métodos de arrays y callbacks para código más limpio.

01¿Qué son las Funciones Flecha?

Las funciones flecha (arrow functions) son una forma más concisa de escribir funciones introducida en ES6 (2015). En vez de escribir function, se usa una flecha =>. Son especialmente útiles para callbacks y funciones cortas.

💡
Contexto real: La mayoría del código JavaScript moderno usa funciones flecha. Las vas a ver en todos los proyectos de Node.js.

Comparación: función tradicional vs. flecha

javascript
// Función tradicional:
function sumar(a, b) {
  return a + b;
}

// Función flecha equivalente:
const sumar = (a, b) => {
  return a + b;
};

// Forma aún más corta (return implícito):
const sumar = (a, b) => a + b;

02Variantes de Sintaxis

La función flecha tiene varias formas según cuántos parámetros tenga y si el cuerpo es de una o varias líneas:

Sin parámetros — () => { ... }

javascript
const saludar = () => {
  console.log('Hola!');
};
saludar();

Un parámetro — param => ... (sin paréntesis)

javascript
const doble = n => n * 2;
console.log(doble(5)); // 10

const mayusculas = texto => texto.toUpperCase();
console.log(mayusculas('hola')); // 'HOLA'

Varios parámetros — (a, b) => ...

javascript
const sumar  = (a, b) => a + b;
const restar = (a, b) => a - b;
console.log(sumar(10, 3));  // 13
console.log(restar(10, 3)); // 7

Cuerpo de varias líneas — necesita return explícito

javascript
const calcularTotal = (precio, cantidad, descuento = 0) => {
  const subtotal = precio * cantidad;
  const ahorro   = subtotal * descuento;
  return subtotal - ahorro;
};
console.log(calcularTotal(100, 3, 0.1)); // 270

Retornar un objeto — envolver con paréntesis ( )

javascript
// Sin paréntesis las llaves se confunden con el cuerpo de la función:
// const crear = nombre => { nombre: nombre }; // MAL ✗

// Con paréntesis: le decimos a JS que es un objeto:
const crearUsuario = nombre => ({ nombre, activo: true });
console.log(crearUsuario('Ana'));
// { nombre: 'Ana', activo: true }
💡
Shorthand property: Cuando la clave y la variable tienen el mismo nombre, podés abreviar. En vez de { nombre: nombre } escribís { nombre }. Se usa mucho en el backend.

03Funciones Flecha con Arrays

Las funciones flecha brillan cuando se combinan con los métodos de arrays como map, filter y reduce. El código queda muy limpio y expresivo:

javascript
const productos = [
  { nombre: 'Teclado', precio: 5000,   categoria: 'perifericos'  },
  { nombre: 'Monitor', precio: 45000,  categoria: 'pantallas'    },
  { nombre: 'Mouse',   precio: 2000,   categoria: 'perifericos'  },
  { nombre: 'Laptop',  precio: 150000, categoria: 'computadoras' },
];

// Con función tradicional:
const precios1 = productos.map(function(p) { return p.precio; });

// Con función flecha (mucho más limpio):
const precios2 = productos.map(p => p.precio);
console.log(precios2); // [5000, 45000, 2000, 150000]

// filter:
const perifericos = productos.filter(p => p.categoria === 'perifericos');
console.log(perifericos.length); // 2

// Encadenando: periféricos con precio > 3000
const resultado = productos
  .filter(p => p.categoria === 'perifericos')
  .filter(p => p.precio > 3000);
console.log(resultado); // solo el Teclado

// find con flecha:
const monitor = productos.find(p => p.nombre === 'Monitor');
console.log(monitor?.precio); // 45000

04Cuándo NO usar Función Flecha

Las funciones flecha son muy útiles pero no son un reemplazo total de las funciones tradicionales. Hay situaciones donde no se deben usar:

NO en métodos de objetos — this no funciona bien

javascript
const obj = {
  nombre: 'Servidor',
  // MAL: función flecha no tiene su propio 'this'
  saludarMal:  () => console.log(`Hola desde ${this?.nombre}`),
  // BIEN: función tradicional
  saludarBien: function() { console.log(`Hola desde ${this.nombre}`); },
};

obj.saludarMal();  // 'Hola desde undefined'
obj.saludarBien(); // 'Hola desde Servidor'

NO como funciones constructoras

javascript
// MAL:
const Persona = (nombre) => { this.nombre = nombre; };
// new Persona('Ana'); // Error: Persona is not a constructor

// BIEN:
function Persona(nombre) { this.nombre = nombre; }
const ana = new Persona('Ana'); // OK
⚠️
Regla práctica: Usá funciones flecha para callbacks, métodos de arrays y funciones cortas. Usá funciones tradicionales para métodos de objetos y constructores.
