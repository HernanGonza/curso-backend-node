Métodos de Arrays

Dominá las tres herramientas más poderosas para procesar datos en JavaScript: map() para transformar, filter() para filtrar y reduce() para acumular. La clase más práctica del bloque.

60 minutos Requiere Clase 10
Objetivos de la clase
  • Dominar map() para transformar arrays.
  • Dominar filter() para filtrar elementos.
  • Dominar reduce() para acumular valores.
  • Encadenar métodos para operaciones complejas.
  • Aplicar estos métodos a datos reales de backend.
  • Resolver problemas de procesamiento de datos comunes.

01map(): Transformar un Array

💡
map() = aplicar una transformación a cada elemento y obtener un nuevo array.

map() recorre el array y aplica una función a cada elemento. Devuelve un nuevo array con los resultados. El array original NO se modifica. El nuevo array siempre tiene la misma cantidad de elementos.

✅
Regla: Si querés TRANSFORMAR cada elemento, usás map().
javascript
const precios = [100, 250, 80, 400, 150];

// Aplicar 21% de IVA a cada precio
const preciosConIVA = precios.map(precio => precio * 1.21);
console.log(preciosConIVA); // [121, 302.5, 96.8, 484, 181.5]
console.log(precios);       // [100, 250, 80, 400, 150] — sin cambios

// Extraer solo los nombres de un array de objetos
const usuarios = [
  { id: 1, nombre: 'Ana',   email: 'ana@mail.com'   },
  { id: 2, nombre: 'Bruno', email: 'bruno@mail.com' },
  { id: 3, nombre: 'Carla', email: 'carla@mail.com' },
];
const nombres = usuarios.map(u => u.nombre);
console.log(nombres); // ['Ana', 'Bruno', 'Carla']

// Sanear datos antes de enviarlos al frontend (ocultar info sensible):
const usuariosSeguros = usuarios.map(u => ({ id: u.id, nombre: u.nombre }));
// [{id:1, nombre:'Ana'}, {id:2, nombre:'Bruno'}, {id:3, nombre:'Carla'}]

02filter(): Filtrar Elementos

💡
filter() = quedarse solo con los elementos que cumplen una condición.

filter() recorre el array y aplica una función a cada elemento. Si la función devuelve true, el elemento se incluye. Si devuelve false, se excluye. El nuevo array puede tener menos elementos que el original.

✅
Regla: Si querés quedarte con un SUBCONJUNTO del array, usás filter().
javascript
const productos = [
  { nombre: 'Laptop',  precio: 150000, stock: 3  },
  { nombre: 'Mouse',   precio: 2000,   stock: 0  },
  { nombre: 'Teclado', precio: 5000,   stock: 10 },
  { nombre: 'Monitor', precio: 45000,  stock: 0  },
  { nombre: 'Webcam',  precio: 8000,   stock: 5  },
];

// Solo productos con stock
const disponibles = productos.filter(p => p.stock > 0);
console.log(disponibles.length); // 3

// Solo productos baratos (menos de 10000)
const baratos = productos.filter(p => p.precio < 10000);
console.log(baratos.map(p => p.nombre)); // ['Mouse', 'Teclado', 'Webcam']

// Patrón típico para "eliminar" sin mutar el array original:
const idAEliminar = 2;
const pedidosFiltrados = pedidos.filter(p => p.id !== idAEliminar);

03reduce(): Acumular en un Solo Valor

💡
reduce() = recorrer el array y acumular todo en UN solo resultado.

reduce() es el más poderoso de los tres. Acumula los elementos del array en un único resultado: puede ser un número, un objeto, otro array, o cualquier cosa. Recibe una función con dos parámetros: el acumulador y el elemento actual.

Sintaxis: arr.reduce((acumulador, elemento) => nuevoAcumulador, valorInicial)

javascript
const ventas = [1500, 2300, 800, 4200, 950];

// Sumar todos los valores:
const total = ventas.reduce((suma, venta) => suma + venta, 0);
console.log(total); // 9750

// Calcular el máximo:
const maximo = ventas.reduce((max, v) => v > max ? v : max, 0);
console.log(maximo); // 4200

// Agrupar por categoría (caso avanzado pero muy útil):
const items = [
  { cat: 'A', valor: 100 }, { cat: 'B', valor: 200 },
  { cat: 'A', valor: 150 }, { cat: 'B', valor: 300 },
];
const porCategoria = items.reduce((acc, item) => {
  acc[item.cat] = (acc[item.cat] || 0) + item.valor;
  return acc;
}, {});
console.log(porCategoria); // { A: 250, B: 500 }

04Encadenamiento de Métodos

La mayor potencia aparece cuando encadenás los métodos. Cada método devuelve un array, y sobre ese array llamás el siguiente:

javascript
const pedidos = [
  { id: 1, cliente: 'Ana',   monto: 5000,  estado: 'entregado' },
  { id: 2, cliente: 'Bruno', monto: 12000, estado: 'pendiente' },
  { id: 3, cliente: 'Carla', monto: 800,   estado: 'entregado' },
  { id: 4, cliente: 'Diego', monto: 25000, estado: 'pendiente' },
  { id: 5, cliente: 'Elena', monto: 4500,  estado: 'cancelado' },
];

// Total de pedidos pendientes mayores a 1000:
const totalPendiente = pedidos
  .filter(p => p.estado === 'pendiente')
  .filter(p => p.monto > 1000)
  .reduce((sum, p) => sum + p.monto, 0);
console.log(`Total pendiente: $${totalPendiente}`); // $37000

// Nombres de clientes con pedidos entregados, en mayúsculas:
const entregados = pedidos
  .filter(p => p.estado === 'entregado')
  .map(p => p.cliente.toUpperCase());
console.log(entregados); // ['ANA', 'CARLA']

// Resumen por estado:
const resumen = pedidos.reduce((acc, p) => {
  acc[p.estado] = (acc[p.estado] || 0) + 1;
  return acc;
}, {});
console.log(resumen); // { entregado: 2, pendiente: 2, cancelado: 1 }
Método¿Qué hace?¿Cuándo usarlo?
map()Transforma cada elemento. Devuelve mismo número de elementos.Querés transformar todos los datos.
filter()Filtra elementos por condición. Puede devolver menos elementos.Querés un subconjunto del array.
reduce()Acumula todo en un único resultado (número, objeto, etc.).Querés totalizar, agrupar o resumir.
