01La Terminal: tu Nueva Mejor Amiga

💻
¿Qué es la terminal?
La terminal (también llamada consola, línea de comandos o CLI) es una pantalla negra donde escribís texto para darle órdenes a la computadora. No tiene botones ni menús — solo comandos de texto.
Ejemplo: en vez de hacer doble clic en una carpeta, escribís cd mi-carpeta y presionás Enter.

Como desarrollador backend vas a usar la terminal para todo: instalar librerías, ejecutar el servidor, ver errores, conectarte a la base de datos. Al principio parece difícil pero en pocas clases se vuelve natural.

Cómo abrir la terminal según tu sistema

WindowsBuscá 'cmd' o 'PowerShell' en el menú inicio. También podés usar la terminal de VS Code.
MacCmd + Espacio, escribí 'Terminal' y Enter. O: Aplicaciones → Utilidades → Terminal.
LinuxCtrl + Alt + T. O buscala en el menú de aplicaciones.
VS CodeCtrl + Shift + ñ. Esta es la que más vas a usar.

02Comandos Básicos de la Terminal

Antes de instalar Node.js, necesitás saber moverte dentro de la terminal. Son pocos comandos y se aprenden rápidamente. La lógica es siempre la misma: escribí el comando y presioná Enter.

Saber dónde estás: pwd

pwd — Print Working Directory. Te muestra en qué carpeta estás parado ahora mismo. Es lo primero que conviene revisar para no perderse.

Terminal
pwd
# La terminal responde algo como:
# /Users/hernan       (en Mac)
# /home/hernan        (en Linux)
# C:\Users\hernan     (en Windows, usar 'dir' en vez de 'pwd')

Ver el contenido de una carpeta: ls / dir

ls (Mac/Linux) o dir (Windows). Lista todos los archivos y carpetas que hay dentro de donde estás. ls -la muestra también los archivos ocultos y los permisos.

Terminal
ls
# Resultado de ejemplo:
# Desktop   Documents   Downloads   mi-proyecto

Entrar a una carpeta: cd

cd — Change Directory. Te mueve a otra carpeta. cd .. con dos puntos te lleva a la carpeta anterior (subir un nivel).

Terminal
cd Desktop            # Entrar a la carpeta Desktop
cd mi-proyecto        # Entrar a la carpeta mi-proyecto
cd ..                 # Volver atrás (subir un nivel)
cd ../otra-carpeta    # Subir un nivel y entrar a 'otra-carpeta'
cd ~                  # Ir directo a tu carpeta de usuario (Mac/Linux)

Crear carpetas y archivos

mkdir mi-backendCrea una carpeta llamada mi-backend
mkdir proyecto/srcCrea carpetas anidadas
touch index.jsCrea un archivo vacío (Mac/Linux)
echo '' > index.jsCrea un archivo vacío (Windows)
rm archivo.jsBorra un archivo (cuidado: sin papelera)
rm -rf carpeta/Borra una carpeta entera (MUCHO cuidado)

Otros comandos útiles

clear / clsLimpia la pantalla (clear Mac/Linux, cls Windows)
Ctrl + CDetiene el proceso que está corriendo — muy usado
↑ (flecha arriba)Muestra el comando anterior — para no reescribir
TabAutocompleta el nombre del archivo o carpeta
historyMuestra todos los comandos que ejecutaste antes
⚡
El Tab es tu mejor atajo. Si escribís cd Des y presionás Tab, la terminal autocompleta a cd Desktop automáticamente. Si hay varias opciones que empiezan igual, presioná Tab dos veces para verlas todas. Usalo siempre — evita errores de tipeo.
⚠️
Los errores de terminal son normales. Si dice 'command not found' o 'No such file or directory', no rompiste nada. Significa que escribiste mal el comando o que no estás en la carpeta correcta. Usá pwd para verificar dónde estás y ls para ver qué hay ahí.

03Instalar Node.js

⚙️
¿Qué es Node.js?
JavaScript nació para correr dentro del navegador (Chrome, Firefox). Node.js es un programa que permite ejecutar JavaScript FUERA del navegador, directamente en tu computadora o en un servidor. Es el motor que vamos a usar para construir el backend.
Sin Node.js, JavaScript solo puede ejecutarse dentro de una página web. Con Node.js, puede ejecutarse en cualquier lugar — incluso en servidores en la nube.

Node.js tiene dos versiones disponibles: LTS (Long Term Support) y Current. Siempre instalá la versión LTS — es la estable, probada y recomendada para producción. La 'Current' tiene las últimas novedades pero puede tener bugs.

VS Code (Visual Studio Code) es un editor de texto especialmente diseñado para escribir código. A diferencia del Bloc de Notas o Word, VS Code entiende el código: lo colorea, detecta errores mientras escribís y tiene autocomplete. Es gratuito, de código abierto, y es el editor más usado del mundo para JavaScript y Node.js.

04bInstalar Postman

📬
¿Qué es Postman?
Postman es una aplicación que te permite enviar requests HTTP a cualquier API y ver la respuesta, sin necesidad de escribir código ni abrir el navegador. Es la herramienta estándar de la industria para testear y documentar APIs.
Básicamente: cuando construyas un endpoint en el curso, vas a usar Postman para probarlo — mandás un GET, POST, PUT o DELETE y ves exactamente qué devuelve el servidor.

No lo usamos todavía — empieza a ser útil a partir del Bloque 4 cuando creemos los primeros servidores. Pero lo instalamos ahora para tenerlo listo.

1
Entrá a postman.comHacé clic en el botón "Download the App" — no uses la versión web
2
Descargá el instalador para tu sistema operativoWindows (.exe), Mac (.dmg) o Linux (.tar.gz)
3
Instalá y abrí PostmanEn Windows: ejecutar el .exe. En Mac: arrastrar a Aplicaciones.
4
Creá una cuenta gratuita o saltá ese pasoPodés usar Postman sin cuenta — hacé clic en "Skip and go to the app"
5
Cerrá Postman por ahoraEstá instalado y listo. Lo vamos a usar a partir del Bloque 4.
💡
¿Para qué lo vamos a usar exactamente?
Cuando en el Bloque 4 creemos el primer servidor con Node.js, vas a abrir Postman, escribir la URL del servidor (http://localhost:3000/api/usuarios), elegir el método (GET, POST, etc.), y hacer clic en Send. El servidor responde y Postman te muestra el JSON de respuesta, el código de estado (200, 404, etc.) y el tiempo que tardó.

Es exactamente lo que hacías con DevTools en YouTube en la Clase 1 — pero esta vez el servidor lo construís vos.

05npm: el Gestor de Paquetes

📦
¿Qué es npm?
npm (Node Package Manager) es una herramienta que viene instalada junto con Node.js. Sirve para descargar e instalar librerías (llamadas 'paquetes') que otros programadores publican para que todos puedan usarlas.
Es como una tienda de ingredientes para cocinar: vos no necesitás hacer la harina desde cero. Vas a la tienda (npm) y la descargás con un comando.

Comandos npm que vas a usar siempre

npm init -yCrea un proyecto nuevo con configuración por defecto. Genera package.json automáticamente.
npm install expressDescarga e instala el paquete 'express'. Podés reemplazar 'express' por cualquier nombre.
npm installInstala todos los paquetes listados en package.json. Se usa cuando clonás un proyecto de GitHub.
npm install -g nodemonInstala nodemon de forma global en tu computadora (no solo en el proyecto). La -g significa global.
npm uninstall expressDesinstala el paquete 'express'.
npm run devEjecuta el script llamado 'dev' del package.json.
npm listLista todos los paquetes instalados en el proyecto.

El archivo package.json explicado línea por línea

Cuando ejecutás npm init -y se crea este archivo automáticamente. Es el 'DNI' de tu proyecto — guarda toda la información importante.

package.json
{
  "name": "mi-backend",       ← Nombre del proyecto (sin espacios ni mayúsculas)
  "version": "1.0.0",         ← Versión actual del proyecto
  "description": "Mi API",    ← Descripción opcional
  "main": "index.js",         ← Archivo principal — por donde arranca el proyecto
  "scripts": {                ← Comandos personalizados que podés ejecutar con npm run
    "start": "node index.js", ← npm start  →  ejecuta node index.js
    "dev":   "nodemon index.js" ← npm run dev  →  ejecuta con nodemon
  },
  "dependencies": {           ← Lista de paquetes instalados
    "express": "^4.18.2"      ← Express v4.18.2 o superior compatible
  }
}
🚫
REGLA DE ORO: node_modules NUNCA se sube a GitHub. Cuando instalás un paquete con npm, se crea una carpeta llamada node_modules que puede pesar cientos de megas. Se agrega al archivo .gitignore y punto. Cuando alguien clona tu proyecto, solo ejecuta npm install y todo se reinstala solo.

¿Qué es console.log?
console.log() es la forma más básica de mostrar información en la terminal. Todo lo que pongas dentro de los paréntesis aparece impreso en pantalla. Es la herramienta principal para ver qué está pasando en tu código — si una variable tiene el valor correcto, si una función se ejecutó, etc.
Es como el 'imprimir' o 'print' de otros lenguajes. En Python es print(), en JavaScript es console.log().

Tipos de datos que podés mostrar con console.log

console.log('Hola mundo');Texto (string) — siempre entre comillas
console.log(42);Número entero — sin comillas
console.log(3.14);Número decimal
console.log(true);Booleano: true o false
console.log('Hola', 'mundo', 123);Varios valores separados por coma
const nombre = 'Ana';Guardamos un valor en una variable
console.log(nombre);Mostramos la variable — imprime: Ana
console.log("Hola, " + nombre);Concatenamos texto con + — imprime: Hola, Ana
console.log(`Hola, ${nombre}!`);Template literal con `` — más fácil de leer
💡
Las comillas simples, dobles y el backtick: En JavaScript podés usar comillas simples ('texto'), dobles ("texto") o backtick (`texto`). Las tres funcionan igual para texto simple. La diferencia del backtick es que permite insertar variables adentro con ${variable}. En este curso usaremos comillas simples para texto y backtick cuando necesitemos variables.

Escribí este código en tu archivo index.js

index.js
// Las dos barras son comentarios — Node.js los ignora
// Sirven para explicar el código

// Variables simples
const nombre = 'tu nombre acá';
const edad = 25;
const curso = 'Backend desde Cero';

// Mostrar en pantalla
console.log('Hola, ' + nombre + '!');
console.log(`Tengo ${edad} años`);
console.log(`Estoy aprendiendo: ${curso}`);

// Operaciones matemáticas
console.log('Suma:', 10 + 5);
console.log('Resta:', 10 - 5);
console.log('Mult:', 10 * 5);
console.log('División:', 10 / 5);

// Node.js tiene módulos propios
// 'require' sirve para importar módulos
const os = require('os');
console.log('--- Info del sistema ---');
console.log('Sistema operativo:', os.platform());
console.log('CPUs disponibles:', os.cpus().length);
console.log('RAM libre:', Math.round(os.freemem() / 1024 / 1024), 'MB');

07Nodemon: Recarga Automática

Cada vez que cambiás el código, tenés que hacer Ctrl+C para detener Node y después volver a escribir node index.js para ver los cambios. Si hacés esto 50 veces por hora, se vuelve muy molesto. Nodemon resuelve esto: monitorea los archivos y cuando detecta un cambio, reinicia el servidor automáticamente.

Terminal — instalación global (una sola vez)
npm install -g nodemon
❓
¿Qué significa -g (global)? Cuando instalás un paquete con -g, se instala en tu computadora completa, no solo en el proyecto actual. Así podés usar nodemon en cualquier proyecto sin tener que instalarlo cada vez.
Terminal — cómo usarlo
# En vez de ejecutar:
node index.js

# Ejecutá:
nodemon index.js

# Vas a ver algo como:
# [nodemon] 3.0.1
# [nodemon] to restart at any time, enter 'rs'
# [nodemon] watching path(s): *.*
# [nodemon] starting 'node index.js'
# Hola, Hernán!
# ...
# [nodemon] clean exit - waiting for changes before restart

Agregar nodemon al package.json como script

La forma profesional es definirlo como un script en el package.json:

package.json
{
  "scripts": {
    "start": "node index.js",
    "dev":   "nodemon index.js"
  }
}

# Ahora podés ejecutar el servidor de desarrollo con:
npm run dev

# Y para producción:
npm start
🔥
Probalo: con nodemon corriendo, cambiá cualquier línea de tu index.js (por ejemplo el valor de la variable nombre) y guardá con Ctrl+S. Vas a ver cómo nodemon detecta el cambio y muestra el nuevo resultado en la terminal automáticamente, sin que hagas nada.

08Ejercicio Práctico

Creá un archivo nuevo llamado explorar.js en tu proyecto. Este ejercicio usa módulos nativos de Node.js para explorar tu sistema. Ejecutalo con: nodemon explorar.js

explorar.js
// Importamos dos módulos que vienen con Node.js
// No necesitan instalarse con npm — ya están incluidos
const os   = require('os');    // Información del sistema operativo
const path = require('path');  // Manejo de rutas de archivos

// === INFORMACIÓN DEL SISTEMA ===
console.log('=== Sistema ===');
console.log('OS:', os.platform());          // linux, win32, darwin
console.log('Arquitectura:', os.arch());    // x64, arm64
console.log('CPUs:', os.cpus().length);
console.log('RAM total:', Math.round(os.totalmem() / 1024 / 1024 / 1024), 'GB');
console.log('RAM libre:', Math.round(os.freemem() / 1024 / 1024), 'MB');
console.log('Usuario:', os.userInfo().username);

// === RUTAS DE ARCHIVOS ===
console.log('');
console.log('=== Rutas ===');
console.log('Carpeta actual:', __dirname);  // dónde está este archivo
console.log('Archivo actual:', __filename); // ruta completa de este archivo

// path.join combina partes de una ruta de forma correcta
// en cualquier sistema operativo (usa / en Mac/Linux, \ en Windows)
const ruta = path.join(__dirname, 'datos', 'usuarios.json');
console.log('Ruta de ejemplo:', ruta);

// === FECHA Y HORA ===
console.log('');
console.log('=== Fecha y Hora ===');
const ahora = new Date();
console.log('Fecha:', ahora.toLocaleDateString('es-AR'));
console.log('Hora:', ahora.toLocaleTimeString('es-AR'));
console.log('Timestamp:', ahora.getTime()); // milisegundos desde 1970
